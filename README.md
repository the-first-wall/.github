# .github

Organisation profile and org-wide defaults for [The First Wall](https://github.com/the-first-wall).

- [`profile/README.md`](profile/README.md) — the page rendered on the organisation profile.
- [`SECURITY.md`](SECURITY.md) — default security policy for every repository in the org.
- [`CONTRIBUTING.md`](CONTRIBUTING.md) — default contribution rules for every repository in the org.

The project itself lives in [ledger](https://github.com/the-first-wall/ledger) (the Merkle ledger, `spec.md`, `skill.md`), [web](https://github.com/the-first-wall/web) (the static explorer at [thefirstwall.ai](https://thefirstwall.ai)) and [x402-worker](https://github.com/the-first-wall/x402-worker) (the stateless x402 shim).
